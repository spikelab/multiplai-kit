# Local skills

This directory is for **your own** Claude Code skills: one directory per
skill containing a `SKILL.md` (frontmatter + prompt) and optionally
`scripts/`, `references/`, or supporting files.

The Multiplai skill library itself is not stored here — it ships as themed
plugins from the marketplace (`/plugin marketplace add
spikelab/multiplai-cc-mktplace`). See `docs/SKILLS.md` at the kit root for
the pack index.

Local skills take precedence over plugin skills of the same name in the
context-routing catalog.
