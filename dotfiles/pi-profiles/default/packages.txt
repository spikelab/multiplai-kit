# Keeps DeepSeek's prefix cache intact across a session. pi's own system prompt
# embeds the current date and working directory, which change between sessions
# and invalidate the whole prefix; compaction rewrites history and invalidates
# it again. This freezes the first and makes the second deterministic, and adds
# /cache-stats, /cache-graph and /cache-reset. Passes through unchanged on
# non-deepseek-* models.
#
# UNVERIFIED: it activates on `deepseek-*` model ids. Whether the OpenRouter
# slugs (`deepseek/deepseek-v4-pro`) match has not been checked; if /cache-stats
# reports nothing after a few turns there, it is not seeing that model.
